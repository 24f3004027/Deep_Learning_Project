BiGRU + Self-Attention

Combines 128-dimensional continuous embeddings with a Bidirectional GRU and a trainable Self-Attention Pooling layer to weight key context tokens across prompts.

🎯

10-Seed Ensembling

Averages predicted Softmax probability distributions across 10 distinct random seeds (42, 123, 2026, 888...) to smooth decision boundaries and prevent distribution shifts.

🛡️

Leakage Elimination

Enforces prompt-level deduplication (subset=['prompt']) to strip target leakage across cross-validation splits and ensure out-of-fold generalization.

⚡

Prior Fallback Engine

Calculates confidence probability gaps between top predictions, defaulting to high-probability class priors ("B C A") for uncertain samples below threshold 0.30.
